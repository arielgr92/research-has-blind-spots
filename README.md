# Research Has Blind Spots

A public, single-page HTML field guide to research gaps across eleven health conditions. It includes source links, donation resources, animated scientific illustrations, and English, Spanish, and French views.

## View locally

Open `neglected-ten-research-gap.html` in a modern browser. It loads `field-guide-design.css` and `field-guide-design.js` from the same directory.

## Files

- `neglected-ten-research-gap.html` — page content and source links
- `field-guide-design.css` — responsive visual design
- `field-guide-design.js` — illustrations, motion, language selector, and translations

## Notes

Figures are contextual indicators, not a global ranking of the least-funded diseases. Consult the page’s linked primary sources for definitions and updated data.
